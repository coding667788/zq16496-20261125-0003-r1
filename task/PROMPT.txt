请从零实现 vaultdrill，用于复核灾后恢复方案是否会把封存资料交给错误人员。输入是不可变的增量快照目录。每份快照包含父引用、对象摘要、删除标记、恢复时间窗、可访问区域及访问规则版本。对象名可改、对象 ID 稳定，删除标记只能遮住继承路径上的副本。一台恢复节点在给定窗内只能使用一个区域，选中增量必须能追到一份可访问的完整快照；同一工作集恢复时必须在所有对象的许可窗口交集内。
实现 evaluate CASE PLAN，返回可恢复实体、每个对象经哪条快照链得到、最终允许哪些组读，以及不可恢复的最小失败证据。再实现 recommend，为 14 个受影响工作集选择至多 18 个候选恢复动作，保证所有强制对象恢复、不得带出仍封存的对象，依次最小化停工分钟、动作数和升序 ID。多个工作集可以共享恢复节点但同一区域约束仍适用。样例需要覆盖父层对象表被删除再新增，以及各对象单独可恢复但没有共同时间窗。Windows Python 3.12 标准库，离线、UTF-8 JSON CLI、README 与小规模穷举对拍。
